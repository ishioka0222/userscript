# Save Page as Markdown

表示中のページの本文（または選んだ要素）を Markdown に変換して、`.md` ファイルとしてダウンロードします。
ログインが必要で `curl` などでは取得できないページを、軽量な Markdown のスナップショットとして保存する用途を想定しています。

Tampermonkey のメニューに次のコマンドを追加します。

| コマンド                             | 内容                                                                                                                                                                                         |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 本文を Markdown でダウンロード       | `main` / `article` / `[role="main"]` などの定番セレクタで本文を自動判定して変換します。見つからない場合は `body` 全体を対象にし、`nav` / `header` / `footer` / `aside` / `form` を除外します |
| 要素を選んで Markdown でダウンロード | ピッカーモードになり、マウスオーバーでハイライトされた要素をクリックすると、その要素以下だけを変換します（Esc でキャンセル）。ナビゲーションを除いて本文だけを確実に取りたいときはこちら     |

出力の先頭には、いつどこを保存したものか分かるよう YAML フロントマターが付きます。

```markdown
---
title: "ページタイトル"
source: https://example.com/doc
saved: 2026-08-23
---

# 見出し

…
```

ファイル名は `<ページタイトル>_<YYYY-MM-DD>.md` です。

## インストール

[Install](https://raw.githubusercontent.com/ishioka0222/userscript/master/scripts/save-page-as-markdown/save-page-as-markdown.user.js)

※ 事前に [Tampermonkey](https://www.tampermonkey.net/) などのユーザースクリプトマネージャーが必要です。

## 対象ページ

- `*://*/*`（すべての http / https ページ。iframe 内では動作しません）

ページ読み込み時に行うのはメニューコマンドの登録だけで、ページの内容は変更しません。

## 変換の仕様

- 変換には [turndown](https://github.com/mixmark-io/turndown) と [turndown-plugin-gfm](https://github.com/mixmark-io/turndown-plugin-gfm)（いずれも MIT ライセンス）を使用します。見出しは ATX 形式（`#`）、コードブロックはフェンス形式、箇条書きは `-`、テーブル・打ち消し線などの GFM 記法に対応します。
- 変換は対象要素を `cloneNode` した複製に対して行い、ページの DOM は変更しません。
- `script` / `style` / `noscript` / `template` / `iframe` / `canvas` は常に除外します。

## 外部ライブラリの取り込みについて

- ライブラリは `@require` で取り込みます。**インストール（更新）時に一度だけ** jsDelivr から取得されて Tampermonkey にキャッシュされ、ページ閲覧時に外部通信は発生しません。
- URL はバージョン固定で、**SHA-256 ハッシュによる整合性検証付き**です。CDN 側でファイルが差し替えられた場合は読み込まれません。

## 注意事項

- 変換品質はページの HTML 構造に依存します。複雑なレイアウト（多段グリッドやカスタム要素の多い画面）では、崩れた場合に「要素を選んで…」で対象を絞るのが有効です。
- CSP の `sandbox` でダウンロードが禁止されているページでは保存できないことがあります。
- 画像はリンク（`![alt](URL)`）として出力されます。画像ファイル自体は保存しません。

## 依存しているサイト内部の実装

なし（ページの DOM・`document.title`・`location.href` のみを使用します）。
