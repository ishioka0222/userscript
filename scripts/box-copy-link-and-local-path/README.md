# Box - Copy Link and Local Path

[Box](https://www.box.com/) の Web アプリで開いているファイル / フォルダについて、共有リンクをリンクとして、またはローカルの Box Drive のパスをクリップボードにコピーします。
Tampermonkey のメニューに次のコマンドを追加します。

| コマンド                       | コピーされる内容                                                                                                  |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Markdown リンクをコピー        | `[<ファイル名 or フォルダパス>](<共有リンク>)`                                                                    |
| リッチテキストリンクをコピー   | `<a href="<共有リンク>"><ファイル名 or フォルダパス></a>`（text/html）と `<共有リンク>`（text/plain）             |
| ローカルの Box パスをコピー    | `<ローカルの Box フォルダ>\<フォルダ階層>[\<ファイル名>]`（例: `%UserProfile%\Box\プロジェクト\資料\仕様書.pdf`） |
| ローカルの Box フォルダを設定… | ローカルパスの先頭部分を変更します（既定: `%UserProfile%\Box\`。空にすると既定値に戻ります）                      |

- ファイル（プレビュー）を開いている場合、リンクテキストはファイル名になります。
- フォルダを開いている場合、リンクテキストは「すべてのファイル」を除いたフォルダパス（`/` 区切り）になります。

## インストール

[Install](https://raw.githubusercontent.com/ishioka0222/userscript/master/scripts/box-copy-link-and-local-path/box-copy-link-and-local-path.user.js)

※ 事前に [Tampermonkey](https://www.tampermonkey.net/) などのユーザースクリプトマネージャーが必要です。

## 対象ページ

- `https://*.box.com/*`（`app.box.com` や企業ごとのサブドメインを含む）

## 使い方

1. Box でファイルのプレビュー、またはフォルダを開きます。
   - ローカルパス / フォルダパスはパンくずリストから組み立てるため、**フォルダからファイルを開いた状態**で実行してください（共有リンクなどからファイルを直接開いた場合はフォルダ階層を取得できません）。
2. ツールバーの Tampermonkey アイコンをクリックします。
3. 「Box - Copy Link and Local Path」の下に表示されるコマンドをクリックします。
4. クリップボードにコピーされ、内容が alert で表示されます。
   - リンクをコピーする場合、Box の「共有」ボタンが自動的に押され、共有リンクのポップアップが開きます（ポップアップはそのまま残るので Esc などで閉じてください）。
   - 共有リンクを作成できない項目（権限が無い場合など）ではエラーになります。

## 注意事項

- ローカルパスは Windows の Box Drive の既定フォルダ（`%UserProfile%\Box\`）を前提にしています。別の場所に同期している場合や macOS の場合は「ローカルの Box フォルダを設定…」で変更してください（区切り文字は `\` 固定です）。
- Box の Web アプリの DOM 構造に依存しているため、Box 側の変更で動かなくなることがあります。

## 動作の仕組み

- ファイルプレビュー（`.preview-container`）があればファイル、パンくずリスト（`.ItemListBreadcrumb`）があればフォルダとして扱います。
- フォルダ階層はパンくずリストから取得します。階層が深くて「その他のフォルダ」に折りたたまれている場合はメニューを一時的に開いて読み取り、読み取り後に閉じます。
- 共有リンクは「共有」ボタンをクリックし、表示される共有リンク入力欄（最大 3 秒待機）から取得します。
- テキストのコピーには `GM_setClipboard` を使います。リッチテキストは `navigator.clipboard.write` を使い、ページがフォーカスを取り戻すまで（最大 3 秒）待ってから書き込みます。失敗した場合は代わりに Markdown リンクをテキストとしてコピーします。

## 依存しているサイト内部の実装

以下が変更されると動作しなくなります。

| 区分     | 対象                       | セレクタ / 内容                                                                            |
| -------- | -------------------------- | ------------------------------------------------------------------------------------------ |
| 判定     | ファイルプレビュー         | `.preview-container`（存在すればファイルとして扱う）                                       |
| 判定     | パンくずリスト             | `.ItemListBreadcrumb`                                                                      |
| 判定     | ファイル名                 | `.preview-container` 内の `h1[data-testid="preview-item-name"]`                            |
| パンくず | 「その他のフォルダ」ボタン | `button.FolderTreeButton`（`aria-expanded` / `aria-controls` でメニューを参照）            |
| パンくず | 折りたたまれたフォルダ     | 上記メニュー内の `li > a`                                                                  |
| パンくず | 表示中のリスト             | `.ItemListBreadcrumb-list:not(.is-measurer)`（`.is-measurer` は幅測定用の複製）            |
| パンくず | 階層のリンク               | `.ItemListBreadcrumb-link`                                                                 |
| パンくず | 現在のフォルダ名           | `.ItemListBreadcrumb-currentItemTitle`                                                     |
| パンくず | ルート                     | 先頭要素は「すべてのファイル」（言語設定で名称が変わる）なので除外                         |
| 共有     | 共有ボタン                 | `[data-testid="one-click-share-button"]`（ファイルの場合は `.preview-container` 内に限定） |
| 共有     | 共有リンク入力欄           | `input[value^="https://"][value*=".box.com/s/"]`（複数ある場合は最後の要素）               |
